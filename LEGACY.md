# MacroEngine — code WPF archivé

Ce dépôt contient l’historique de la version **WPF / .NET** de MacroEngine.

Pour retrouver ce code après le reboot Tauri (branche `v2`) :

- branche Git : `legacy/wpf`
- tag : `legacy-wpf`

```bash
git checkout legacy/wpf
# ou
git checkout legacy-wpf
```

Le développement actif v2 (Tauri 2 + React + Rust) se fait sur la branche `v2`.
